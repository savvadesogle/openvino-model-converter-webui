Task

Choose "convert to OpenVINO" to keep the original weights, or "compress via NNCF" for mixed-precision quantization.

Weight mode

Modes are loaded dynamically from the installed NNCF version. “int2-mix” reproduces the AutoRound mixed scheme (experts int2, rest int4) and requires a MoE model.

If a mode shows “not available in the installed NNCF”, that mode is missing from your installed NNCF's CompressWeightsMode enum. To fix: upgrade NNCF (pip install -r requirements.txt or pip install --upgrade nncf in the openvino-latest env), or pick a different mode. The “Self-test modes” button shows which modes pass a tiny compress+compile on this environment.

Compression

Group size shares one scale per group; -1 means per-channel. INT8 modes require per-channel. Ratio/backup apply to single-pass mixed precision.

Data-aware methods (optional)
Available only when “Compress via NNCF” and an INT4/INT2/INT3/nf4/fp8 mode is selected. Not available for INT8, cb4, mxfp (fixed), or mixed (int2-mix/int3-mix) modes. AWQ, GPTQ and LoRA correction need a calibration dataset (.npy); Scale estimation runs without one.
Number of calibration input samples (rows of the .npy array) NNCF uses for data-aware calibration. Higher = slower but better-calibrated compression. Typical range 16-256; 128 is a good default. Must not exceed the number of rows in the .npy file.
Path to a .npy file containing a single numpy array of input tensors for calibration — shape (N, ...) where N is the number of samples and the rest is one model input. You can build it by running your model on sample prompts and saving the input tensor(s) with numpy.save('inputs.npy', arr). Must be a .npy (NumPy) file loadable by numpy.load; only the first num_samples rows are used. Needed for AWQ, GPTQ and LoRA correction only (Scale estimation runs without it). See NNCF docs (github.com/openvinotoolkit/nncf).

Submodels

For VLMs: compress only the language model + text embeddings and keep vision in fp16 (faster, and vision is tiny).

Use for VLMs (vision-language models): compress only the language model + text embeddings and keep the (tiny) vision submodels in fp16 — much faster conversion with negligible size difference. For text-only models this has no effect. Disable it only if you want absolutely every submodel compressed.

Output

Result path. The name follows the HF OpenVINO convention “<Base>-<mode>-ov”, with “-ov” always last.

During conversion the model is first exported to a dense fp16 OpenVINO IR, then compressed. That intermediate copy is stored at \<Base>-fp16-ov (the same folder where the final model is written, under savvadesogle). Tick this to delete it after the run (keeps disk tidy); untick to keep it (e.g. to reuse it for several compression runs).
After conversion, runs the model through OpenVINO GenAI to verify it works end-to-end (loads the converted dir, generates a short sample, reports tokens/sec).
from ov_converter.genai_test import run_test, format_result

res = run_test(r"T:\models\savvadesogle\<Base>-<mode>-ov", max_new_tokens=24)
print(format_result(res))

Checks & Run

Buttons are disabled until disk and virtual-memory checks pass.

This project pins exact library versions in requirements.txt. “Install required transformers” (or auto-install) temporarily swaps the shared Python env to a different transformers version needed by a specific model. Click “Restore pinned versions” to switch the env back to the pinned requirements.txt versions — use it after a manual install, or to clean up a swap that didn't finish.

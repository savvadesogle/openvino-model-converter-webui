OpenVINO Model Converter

Model

Paste a Hugging Face link, a bare model id like Qwen/Qwen3.5-0.8B, or a local path. The tool validates it before downloading.

Options

Revision and token are optional. Gated models need an HF token; the include filter fetches only what is needed for conversion.

Destination & checks

Editable target directory. The download button stays disabled until the disk space check passes.

Files to download

Model

Choose a locally scanned model (dense, not GGUF/quantized/OV), or paste a HF link / local path. If it is not downloaded yet, check “Download first”.

Task

Auto-detected from config.json (vision models map to image-text-to-text).

Weight mode

Modes are loaded dynamically from the installed NNCF version. “int2-mix” reproduces the AutoRound mixed scheme (experts int2, rest int4) and requires a MoE model.

Compression

Group size shares one scale per group; -1 means per-channel. INT8 modes require per-channel. Ratio/backup apply to single-pass mixed precision.

Data-aware methods (optional)

Submodels

For VLMs: compress only the language model + text embeddings and keep vision in fp16 (faster, and vision is tiny).

Output

Result path. The name follows the HF OpenVINO convention “<Base>-<mode>-ov”, with “-ov” always last.

Checks & Run

Buttons are disabled until disk and virtual-memory checks pass.
